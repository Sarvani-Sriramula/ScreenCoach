# Mindful Screen Coach

An Android app that helps students reduce excessive screen time through motivational micro-interventions.

## 📱 Features
- Detects 10+ minutes of continuous screen use
- Sends motivational nudges (impact + healthy action)
- Tracks which messages are effective
- Daily summaries and weekly charts
- Adaptive message recommender
- Full privacy: all data stored locally

## 🧩 Architecture
See `mindful_screen_coach_architecture.png` for system architecture.

## 🚀 Technologies Used
- Android (Kotlin)
- UsageStatsManager
- Room Database
- NotificationCompat
- MPAndroidChart
- Kotlin Coroutines
- WorkManager (optional)
- CSV Export
- Scikit-learn (offline modeling)

## 🛠️ Setup Instructions
1. Clone this repo
2. Open in Android Studio
3. Enable Usage Access permission on your device
4. Build and run on Android API 23+
